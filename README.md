# ❀ Songanali ❀ — The deeper meaning behind music

**Live site: https://zeinaelsawy.github.io/PersonalProject/**

Songanali is my personal project: a one-page website that looks at the implicit meaning behind song lyrics. I chose "After the Storm" by Kali Uchis (featuring Tyler, The Creator and Bootsy Collins) because it deeply resonates with me.

## What's on the page

- **Proposal** – a short introduction to the project and why I picked this song.
- **Artist** – a brief background on Kali Uchis.
- **Lyrics** – links to listen to the song and read the lyrics on their official sources.
- **Analysis** – my reading of the song: its message of self-reliance, the "look both ways" wordplay in the intro, the storm, sun and flowers imagery, and the umbrella as a metaphor for support. A "Read more" button expands the full text.

## Features

- Fixed navigation bar with a dropdown that jumps to each section
- Login and create-account forms that switch in place, with input validation and a confirmation popup
- Expandable "Read more / Read less" analysis section

The login and sign-up forms are a front-end demo only. There is no backend, so nothing typed into them is saved or sent anywhere.

## Built with

Plain HTML, CSS and JavaScript. No frameworks, libraries or build step.

## Run it locally

```
git clone https://github.com/zeinaelsawy/PersonalProject.git
cd PersonalProject
```

Then open `index.html` in any browser.
